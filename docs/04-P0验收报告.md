## 3. 实测记录

### 3.1 联网路径（真实数据源）

命令：

```powershell
aimoney-data --root data/e2e sync --start 2026-10-01 --end 2026-10-15 --codes 600000 --full --trade-date 2026-10-15
```

结果：

| 接口 | 用途 | 结果 | 证据 |
| --- | --- | --- | --- |
| `tool_trade_date_hist_sina` | 交易日历 | **成功** | 拉取过程有进度输出，日历可用于 `is_trade_day` 判断 |
| `stock_info_a_code_name` | 股票列表 | **成功** | 5000+ 标的；同时触发预期 WARNING：`stock_info.list_date 暂为空` |
| `stock_zh_a_hist` | 日线行情 | **失败（对端限流）** | `ConnectionError: RemoteDisconnected('Remote end closed connection without response')`，重试 3 次后放弃 |

CLI 行为（符合设计预期）：

```
同步结果：daily 2026-10-01~2026-10-15 标的 1 只，取数 0 行，落盘 0 行，失败 1 只，版本 None
失败标的：
  600000: akshare 日线[600000] 失败，已重试 3 次 | {... 'error_type': 'ConnectionError' ...}
退出码：1
```

值得记录的两点：

1. **首轮实测（当日更早）该接口是通过的**——`pytest -m network` 曾 4 条全过，其中包含与 akshare 原始数据逐日对账的用例（`volume == 成交量 × 100` 全等）。此后短时间多次调用即被对端掐断，属 IP 级限流，**不是代码缺陷**。
2. 失败被包装为结构化的 `DataSourceError` 并计入 `SyncResult.failed`，**没有产生任何脏数据**（落盘 0 行），退出码为 1。这正是"宁可失败也不静默降级"的设计目标：限流时宁可当日无数据，也不能写入半份行情。

因此 A1 的"真实全量回填"需在数据源可用时执行：

```powershell
aimoney-data sync --start 2018-01-01 --full --codes <...>   # 或省略 --codes 走全市场
```

### 3.2 离线全链路演练（用真实 CLI 操作引擎产出的数据）

数据由 `DailySyncTask`（注入内存数据源）写入，随后**未经修改的真实 CLI**执行：

```powershell
aimoney-data --root data/e2e list
aimoney-data --root data/e2e coverage
aimoney-data --root data/e2e check --date 2026-10-15
aimoney-data --root data/e2e coverage --json
```

输出（节选）：

```
数据集  行数  标的数  起始        结束        分区  数据版本
--------------------------------------------------------------
daily   21    3       2026-10-09  2026-10-15  1     20261015.1

数据集  行数  标的数  起始        结束        分区  数据版本    最新同步
-----------------------------------------------------------------------------------
daily   21    3       2026-10-09  2026-10-15  1     20261015.1  2026-10-15T10:28:59
交易门禁：关闭（尚未执行数据质量校验）

[PASS] daily 2026-10-15 检查 3 只 / 3 行；未生效：缺失率检查（未提供期望标的列表）
check-exit=0
```

`check` 之后 `coverage --json` 显示门禁翻转：

```json
"gate": { "open": true, "reason": "数据质量 PASS", "as_of": "2026-10-15" }
```

链路确认：**取数 → 复权因子合并 → 幂等落盘（按月分区）→ 数据版本号 → 质量校验 → 日报落盘 → 门禁开关 → 覆盖率查询 → CLI/接口输出**。

演练数据与一次性脚本位于 gitignore 的 `data/e2e`，验收后已删除。
